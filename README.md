# 🛒 React E-Commerce Website

A modern and responsive E-Commerce website built using React.js and Tailwind CSS.  
This project includes product listings, login/signup pages, product details, navigation, and smooth UI components inspired by popular shopping platforms.

---
Live Demo 🚀 : 
        https://frontend-ecommerce-website-kappa.vercel.app/
---

## 🚀 Features

- 🔐 Login & Signup Pages
- 🛍️ Product Listing Page
- 📄 Product Detail Page
- 🔎 Search Functionality
- 🧭 React Router Navigation
- 🎞️ Auto Sliding Banner/Carousel
- 📱 Responsive Design
- ⚡ Fast UI using React + Vite
- 🎨 Styled with Tailwind CSS

---

## 🛠️ Tech Stack

- React.js
- Tailwind CSS
- JavaScript
- React Router DOM
- Vite
